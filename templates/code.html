Code and examples

Two small experiments that show, in a few seconds, why the averaging and extrapolation ideas in my papers matter. Both run in your browser; the same algorithms are available below as short Python scripts.

  • Picard iteration
  • Krasnoselskii–Mann iteration
  • Fixed point

Averaging tames a nonexpansive map

Let \(T\) rotate the plane by an angle \(\theta\) about the origin. It is nonexpansive and its only fixed point is \(0\), yet the Picard iteration \(x_{n+1} = T x_n\) circles forever. The Krasnoselskii–Mann iteration

\[ x_{n+1} = (1-\lambda)\,x_n + \lambda\, T x_n, \qquad 0<\lambda<1, \]

averages each step with the current point and spirals into the fixed point. Enriched nonexpansive mappings are exactly the maps for which a suitable averaging of this kind becomes nonexpansive.

One extra projection makes the difference

Find \(x^\ast \in C = [-1,1]^2\) with \(\langle F x^\ast, y - x^\ast\rangle \ge 0\) for all \(y \in C\), where \(F x = M x + q\) and \(M = \begin{pmatrix}\varepsilon & 1\\ -1 & \varepsilon\end{pmatrix}\). For small \(\varepsilon\) the operator is monotone but far from a gradient, and the projected gradient method \(x_{n+1} = P_C(x_n - \tau F x_n)\) drifts away from the solution. The extragradient method first takes a trial step and then corrects with the operator evaluated there:

\[ y_n = P_C(x_n - \tau F x_n), \qquad x_{n+1} = P_C(x_n - \tau F y_n). \]

Tseng, golden-ratio and inertial variants in my recent papers refine this idea to save projections and to handle non-monotone operators.

Python scripts

Self-contained scripts that reproduce the two experiments and print the error at every iteration. They need only NumPy, and Matplotlib if you want the figure.

  • krasnoselskii_mann.py

    Picard and Krasnoselskii–Mann iterations for a plane rotation.

  • extragradient_vi.py

    Projected gradient and extragradient methods for a box-constrained monotone variational inequality.

pip install numpy matplotlib
python extragradient_vi.py --eps 0 --tau 0.3 --iters 80 --plot
